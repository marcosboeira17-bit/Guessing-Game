
# Guessing Game - Learn English

## About the Project

Guessing Game is an educational web application
designed to help users improve their English vocabulary
through an interactive word guessing game.

## Features

- 30 different words.
- Three English clues for each word.
- Answers in English or Portuguese.
- Random question order.
- Score system.
- Progress bar.
- Responsive design.
- English user manual.

## How to Play

1. Read the clues in English.
2. Enter your answer in English or Portuguese.
3. Click Check Answer.
4. Request more hints if necessary.
5. Earn 10 points for each correct answer.
6. Complete all 30 questions.

## Technologies

- HTML5
- CSS3
- JavaScript

## How to Run

Open the index.html file in your browser
or use the Live Server extension in Visual Studio Code.

## Project Objective

Combine technology and education to make
learning English simple, interactive and fun.
