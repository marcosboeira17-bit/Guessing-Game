1. Introduction

Guessing Game is an educational game designed to help players improve their English vocabulary in a simple and fun way.

2. Objective

The objective is to guess the secret word using clues written in English.

3. How to Play

  1. Read the category and the first clue.
  2. Type your answer in English or Portuguese.
  3. Click the "Check Answer" button.
  4. If your answer is incorrect, try again.
  5. Click "More Hints" if you need help.
  6. Earn 10 points for each correct answer.
  7. Click "Next Word" to continue.
  8. Complete all the questions to finish the game.

4. Game Rules

  • The game contains 30 secret words.
  • Each word has three clues.
  • All clues are written in English.
  • Answers can be in English or Portuguese.
  • You have unlimited attempts.
  • Each correct answer is worth 10 points.
  • The maximum score is 300 points.

5. Example

Category: Food

Clue 1: I am a fruit.

Clue 2: I can be red or green.

Clue 3: I grow on trees.

Correct answer: Apple or Maçã.

6. Restarting the Game

Click "Restart Game" or "Play Again" to start a new game. Your score will be reset and the words will be shuffled.

7. Technologies

  • HTML5 - Website structure.
  • CSS3 - Design and responsive layout.
  • JavaScript - Game logic and interaction.

8. Final Message

Learn English, challenge yourself and have fun!
